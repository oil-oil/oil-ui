# Glossary

Fixed renderings for recurring terms. Use these forms everywhere in `en/` so the
agent meets one word for one concept. Where upstream already chose an English
word (README.en.md, the explorer's `en` strings, style-card labels), that word wins.

## Voice

- Imperative, second person, present tense, as the source. "Decide the skeleton before writing copy."
- Short sentences. One instruction per sentence. No em dashes, no semicolons.
- Keep every number, range, flag, file path, CSS property, and code span exactly.
- Keep the source's bluntness. 毒舌评审 is "a merciless review", not "candid feedback".
- Translate meaning, not characters. 不靠换个颜色补救 is "instead of patching it with a color swap".
- Where the source says 中文 because it assumes a Chinese product, keep "Chinese" only when the rule is specific to CJK typography (line height, line breaking, CJK fonts). Where it means "the product's language", say that.
